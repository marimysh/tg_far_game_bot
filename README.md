# far-bot

Telegram-бот очереди «FAR Помощь» — standalone-перенос с n8n на чистый Node.js без зависимостей.

## Что умеет

- `/farcreate` — многошаговая заявка (тип → ник → число дней) с inline-клавиатурами
- `/farupdate` — обновление «Осталось дней» у заявки
- `/fardelete` — закрытие заявки (статус «Готово (снято)»)
- `/toptop` — первые в очереди по обоим типам
- `/farhelp` — справка
- Дайджест очереди в групповой чат при изменении Google-таблицы (поллинг)

Хранилище заявок — Google Таблица (как в оригинале), состояние диалогов — JSON-файл (`state.json`), лимит — только разрешённые чаты/топики (`ALLOWED_TOPICS`).

## Запуск

Требуется Node.js ≥ 20.

```bash
cp .env.example .env   # заполнить значениями
npm start              # = node src/index.js
```

Long polling: входящий webhook не нужен, перед стартом бот сам делает `deleteWebhook`. Процесс должен работать с таймзоной Europe/Moscow (`TZ=Europe/Moscow`).

## Тесты

```bash
npm test   # сценарии на фейковых Telegram/Sheets клиентах, без сети
```

## Деплой

1. Скопировать каталог на хост, создать рядом `.env` из `.env.example` (права 600).
2. Адаптировать `deploy/far-bot.service`: пользователь/группа хоста, пути к каталогу приложения и к бинарнику Node.js ≥ 20.
3. Установить unit в systemd: `daemon-reload`, `enable --now`.
4. Откат: остановить сервис и вернуть прежнюю реализацию бота.
